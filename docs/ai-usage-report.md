# AI Usage Report

## Tools Used & Use Cases

I used ChatGPT as an AI-assisted support tool while developing this portfolio website. I completed and customized the website myself, while using AI mainly for explanations, troubleshooting, design suggestions, and reviewing my work.

I used ChatGPT for the following tasks:

- Clarifying the assignment requirements and organizing the work into smaller steps.
- Reviewing the HTML structure and checking that the required sections were included.
- Helping with CSS styling and suggesting ways to improve the visual appearance of the website.
- Explaining how Flexbox and media queries can be used to create a responsive layout.
- Helping implement the dark/light mode feature using JavaScript.
- Explaining JavaScript event listeners and how they are used for button and form interactions.
- Helping debug problems when the CSS was not displaying correctly.
- Suggesting improvements to the project cards and overall page layout.
- Reviewing the README and technical documentation to make sure important information was included.
- Suggesting ways to improve the project section when I did not have screenshots or project images available.

AI was therefore used during different stages of the assignment rather than for only one task.

---

## Benefits & Challenges

One of the main benefits of using AI was that I could get explanations quickly when I was unsure about a concept or when something in my code was not working.

For example, I had problems with the website styling at one point because the CSS was not being applied correctly. AI helped me review the structure and identify what needed to be corrected. This helped me understand the importance of correctly linking files and organizing folders.

AI was also useful when working on responsive design. It helped explain how Flexbox allows elements to adjust based on the available space and how media queries can change the layout for smaller devices.

Another useful example was the project section. The assignment suggested using project images, but I did not have suitable screenshots available. Instead of leaving the section empty, I used AI to explore alternative ideas. I then used HTML and CSS to create small visual previews for the projects, such as an event list and an exam schedule. This allowed the project cards to still have a visual element without depending on external images.

There were also challenges when using AI. Not every suggestion worked correctly on the first attempt or matched the style I wanted. Some changes affected the layout, so I had to review the code, restore parts of the design, and adjust the solution.

This showed me that AI-generated suggestions should not be accepted automatically. They still need to be tested, understood, and modified.

---

## Learning Outcomes

Using AI during this assignment helped me improve both my technical skills and my development workflow.

I improved my understanding of:

- Structuring a webpage using semantic HTML sections.
- Separating HTML, CSS, and JavaScript into different files.
- Using Flexbox to organize project and achievement cards.
- Using media queries to make a website responsive.
- Creating consistent colors, spacing, borders, and card styles with CSS.
- Using JavaScript event listeners to respond to user actions.
- Using `classList.toggle()` to switch between light and dark themes.
- Preventing the default behavior of a form using JavaScript.
- Testing and debugging a website after making changes.
- Organizing a project using folders for styles, scripts, assets, and documentation.
- Using GitHub to store and manage the assignment.

I also improved my ability to read code and understand why each part is needed.

For example, I understand that the dark mode button does not directly change every element. Instead, JavaScript adds or removes a `dark-mode` class from the page, and CSS rules define how elements should look when that class is active.

I also understand that the responsive layout works because Flexbox allows cards to adjust their size, while the media query changes the layout when the screen width becomes smaller.

These examples helped me understand the logic behind the code instead of only using the final result.

## Responsible Use & Modifications

I used AI as a development assistant rather than as a replacement for my own work.

I reviewed the suggestions before adding them to the project and modified them when necessary.

Some examples of changes and decisions I made include:

- Choosing the final burgundy and soft pink color theme.
- Modifying the original color suggestions to better match the style I wanted.
- Adding an Achievements section to make the portfolio more complete.
- Choosing which projects and achievements to display.
- Editing the descriptions so that they represent my own experience.
- Replacing normal image placeholders with HTML and CSS project previews.
- Adjusting the layout after some styling changes affected the appearance of the page.
- Testing the dark/light mode and contact form interactions.
- Checking the website after changes instead of assuming generated code would work correctly.

I also kept the code organized and added comments to make important sections easier to understand.

The final website is therefore a combination of my own content, design choices, testing, and modifications, with AI used mainly for guidance and problem-solving.

## Creative and Innovative Use of AI

One way I used AI creatively was when solving the problem of not having project images.

Instead of simply using generic images from the internet, I explored alternatives and created visual project previews using only HTML and CSS.

For the Event Management System, I created a small interface showing upcoming events.

For the Exam Scheduler Database, I created a small schedule showing course codes and exam times.

This approach made the portfolio more visually interesting while keeping the website lightweight and original.

I also used AI to explore different design themes before deciding on the final burgundy and pink style. I compared suggestions, changed the colors, and adjusted the design until it matched the appearance I wanted.

This showed me that AI can be useful not only for generating code, but also for exploring different solutions to a design or development problem.

---

## How I Verified the AI Suggestions

After adding or changing code, I checked the website in the browser and tested the features.

I verified:
- Navigation links between sections.
- Dark and light mode.
- Contact form interaction.
- Project and achievement card layouts.
- Responsive behavior on smaller screen sizes.
- CSS styling and colors.
- File connections between HTML, CSS, and JavaScript.
- That there were no obvious broken elements on the page.

When a suggestion caused a problem, I reviewed it and changed the code until the website worked correctly.

This testing process helped me better understand the AI suggestions and made sure that the final project met the assignment requirements.
