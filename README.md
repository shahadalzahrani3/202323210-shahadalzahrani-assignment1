## Project Description

This project is a responsive personal portfolio website created using HTML, CSS, and JavaScript.

The website introduces me, presents some of my projects and achievements, and includes a contact form. The design uses a burgundy and soft pink color theme and supports both light and dark modes.

## Features

- About Me section
- Projects section
- Achievements section
- Contact form
- Dark and light mode
- Smooth navigation between sections
- Responsive design for desktop, tablet, and mobile
- Interactive contact form message

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Media Queries
- Git and GitHub
